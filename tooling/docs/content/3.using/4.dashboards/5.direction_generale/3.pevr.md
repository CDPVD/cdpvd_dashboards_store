# Déploiement

:badge[tag:pevr]{type="success"}
:badge[nouveauté v0.10.0]

## Bases de données

Les bases de données `gpi` et `jade` doivent être liées au projet.

Veuillez consulter la section [lier une base de données](/using/configuration/linking) pour plus d’informations sur la configuration des connexions.

## Marts requis

Les marts suivants doivent être activés afin d’assurer le bon fonctionnement du tableau de bord :

- `educ_serv`

Veuillez consulter la section [activation d’un mart](/using/configuration/enabling) pour plus d’informations.

### Configuration du projet dbt

> Mettez à jour votre fichier `cssxx_store/dbt_project.yml` avec l’extrait suivant :

```yaml
# cssXX.data.store/dbt_project.yml

models:
  store:
    marts:
      educ_serv:
        +enabled: true
    dashboards:
      pevr:
        +enabled: true
    interfaces:
      gpi:
        +enabled: true
      jade:
        +enabled: true

  cdpvd_dashboards_store:
    dashboards:
      direction_generale:
        pevr:
          +enabled: true
```

::alert{type=info}

Le tableau de bord PEVR utilise également certains rapports provenant de `core.dashboard_store`.

Vous devez donc activer et configurer cette portion du projet afin d’accéder à l’onglet `PEVR : Ministère`, qui contient les indicateurs liés au PEVR du ministère de l’Éducation.

::

# Configuration

::alert{type=warning}

Ce tableau de bord nécessite plusieurs seeds configurés en mode override. Cette configuration est obligatoire. Sans celle-ci, le tableau de bord ne fonctionnera pas correctement.

Veuillez consulter la section [seeds](/using/marts/seeds) pour plus d’informations sur l’utilisation et le peuplement des seeds si nécessaire.

Si le concept d’override vous est inconnu, veuillez consulter la section [overriding](/using/configuration/overriding).

Dans le cas contraire, vous pouvez également créer vos propres indicateurs en réutilisant les données du `core`.

::

Comme mentionné précédemment, ce tableau de bord fonctionne conjointement avec `core.dashboards_store`.

Le schéma des seeds du core se trouve dans :

```text
core.dashboards_store/seeds/dashboards/pevr/schema.yml
```

## Configuration des seeds du core

### 1. `custom_indicateurs_pevr_meq`

Créer le fichier suivant :

```text
cssXX.dashboards_store/seeds/dashboards/direction_generale/pevr/core/custom_indicateurs_pevr_meq.csv
```

Nous recommandons de conserver la même structure que celle du core et de modifier uniquement:

- `id_indicateur_css`
- la description de l’indicateur

afin de refléter vos indicateurs internes.

### 2. `custom_cibles_indicateurs_annuelles_pevr`

Créer le fichier suivant :

```text
cssXX.dashboards_store/seeds/dashboards/direction_generale/pevr/core/custom_cibles_indicateurs_annuelles_pevr.csv
```

Nous recommandons de modifier uniquement la colonne `cible`, qui représente la cible annuelle de l’indicateur associé.

Le `id_indicateur_meq` doit correspondre à celui défini dans le fichier précédent.

### 3. `custom_indicateurs_pevr_charl`

Créer le fichier suivant :

```text
cssXX.dashboards_store/seeds/dashboards/direction_generale/pevr/core/custom_indicateurs_pevr_charl.csv
```

Ce fichier permet d’ajouter vos propres taux provenant de Charlemagne.

Les cibles annuelles doivent correspondre à celles définies dans votre PEVR interne.

## Configuration des seeds CSS

### 4. `custom_indicateurs_pevr_css`

Créer le fichier suivant :

```text
cssXX.dashboards_store/seeds/dashboards/direction_generale/pevr/css/custom_indicateurs_pevr_css.csv
```

Vous devez :

- modifier la colonne `id_indicateur_cdpvd`
- associer vos indicateurs internes aux indicateurs CDPVD
- ajuster les descriptions au besoin

### 5. `custom_cibles_indicateurs_annuelles_pevr_css`

Créer le fichier suivant :

```text
cssXX.dashboards_store/seeds/dashboards/direction_generale/pevr/css/custom_cibles_indicateurs_annuelles_pevr_css.csv
```

Vous devez :

- associer les `id_indicateur_cdpvd`
- vous assurer que `id_indicateur_meq` correspond à celui défini dans le fichier précédent
- définir les cibles annuelles appropriées
