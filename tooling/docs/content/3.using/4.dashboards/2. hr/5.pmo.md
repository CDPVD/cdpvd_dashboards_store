# Déploiement

**Tag :** `human_resources`  

  

## Bases de données

La base de données `paie` doit être liée au projet. 
Il faut mettre en place chacun des tableau de bord mentionné ci-haut de façon individuelle. Référez-vous à la section (/using/4.dashbord/2. hr) pour plus d'informations sur la façon d'installer chacune des tableaux.

Si vous n'avez pas mis en place un de ces tableau, il est tout de même possible de mettre en place le tableau pmo. La mise à jour va passer, mais les graphiques seront en erreur dans les pages des rapports non mis en place.  
  

## Seed


> [!WARNING]

## Marts

Les marts suivants doivent être activés pour que le tableau de bord fonctionne. Veuillez vous référer à la section [Activer un mart](/using/configuration/enabling) pour plus d'informations sur la façon d'activer un mart.

- `human_resources`
  
  
  
## Dbt project specification
> Mettre à jour votre `cssxx.dashboards_store/dbt_project.yml` avec l'extrait de code suivant :
```yaml

```yaml
# cssxx.dashboards_store/dbt_project.yml
models: 
  store:
    marts:
      human_resources:
        +enabled: true  
    interfaces:
      paie:
        +enabled: true
```
